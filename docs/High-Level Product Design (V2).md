
# 0. Core Idea (One Sentence)

A messaging-first Instagram experience that preserves relationships while eliminating algorithmic attention traps.

Everything else is implementation detail.

---

# 1. The Real Problem (Reframed Properly)

Instagram is not "bad" because of content.
It is "bad" because it mixes 3 incompatible systems:
### 1.1 Communication (DMs)
- intentional
- reciprocal
- socially necessary
### 1.2 Social Discovery (feed/explore/reels)
- algorithmic
- infinite
- engagement-optimized
### 1.3 Social Obligation Layer
- "I should reply"
- "I should keep up"
- "I don't want to miss things"

These three get fused into one app → cognitive overload + compulsion loops.

---
Key insight:

Users don't want less Instagram.  
They want Instagram decomposed by intent.

---
# 2. Product Thesis

We explicitly separate Instagram into two modes:

## Mode A — Connection Mode

(what the app is for)

- DMs
- friend-shared media
- intentional viewing only
- bounded interactions

## Mode B — Discovery Mode
(what the app rejects)

- feed
- explore
- reels feed
- algorithmic recommendations
---

# 3. Product Principles

## Principle 1 — Intentional Entry Only
Nothing is surfaced unless:

- a friend sent it
- the user directly opened it
- the user explicitly searched it

No passive discovery surfaces.

---
## Principle 2 — Finite Attention

Every content experience must end.

No infinite scroll loops.

Every session has:
- a stopping condition
- a completion state

---

## Principle 3 — Social First, Content Second
Content is never the product.
Relationships are the product.

---

## Principle 4 — No Algorithmic Escalation

The system must never try to:

- increase engagement
- extend session time
- suggest "more like this"

---

## Principle 5 — Calm is Default

The UI should feel:

- quiet
- predictable
- non-reactive
- non-urgent

---

# 4. Core User Experience

## 4.1 Home = Inbox, not Feed

Sections:

- Unread
- Pinned
- Recent

No stories, reels, explore, or suggestions.

Mental model: messaging inbox, not content platform.

---

## 4.2 Conversation = Primary Unit

Each conversation is a relationship container.

Contains:

- messages
- shared reels
- shared posts

No recommendations ever appear here.

---

## 4.3 Shared Reel = Special Object

Reels exist only as:

> messages between people

Rules:

- only open if sent directly
- no autoplay chain
- no "next reel"
- no recommendations

After viewing:

- return to conversation
- or exit

---

## 4.4 Completion States

Inbox:

- "You're all caught up"

Conversations:

- "Nothing new here"

Reels:

- "End of shared content"

Empty states are features, not gaps.

---

## 4.5 No Passive Browsing Surfaces

Explicitly removed:

- explore page
- reels feed
- suggested users
- trending content

Search is only for intent-based retrieval.

---

# 5. Key Product Innovation — Attention Firewall

## Allowed paths:

- person → conversation
- conversation → shared media
- shared media → return

## Forbidden paths:

- media → recommendation loop
- content → content chain traversal

This is behavioral architecture, not UI design.

---

# 6. Friend-Sent Reels

Reels are:

- preserved
- social
- contextual

But NOT:

- discoverable
- algorithmically suggested
- endlessly chainable

---

# 7. Emotional UX Goals

Users should feel:

- I'm caught up
- I'm not missing anything important
- I can leave now

NOT:

- I should check again
- I need to scroll more

---

# 8. Competitive Positioning

Not:

- messaging app
- social network
- content platform

But:

A relationship-first communication layer over Instagram.

---

# 9. Differentiation

Most apps optimize for engagement.  
This optimizes for attention control.

---

# 10. What Success Looks Like

Users say:

- "I only open it when people message me."
- "I don't get stuck anymore."
- "It feels like iMessage, not social media."

---

# 11. What This Is NOT

- not a new social network
- not a feed alternative
- not a creator platform
- not a recommendation engine

---

# 12. Core System Summary

A constrained communication interface over social media infrastructure.
